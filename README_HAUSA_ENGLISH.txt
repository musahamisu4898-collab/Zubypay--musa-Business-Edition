HAUSA
Wannan sigar ZubaPay v2.1 ce ta offline customer demonstration. A bude index.html da Chrome ko Edge. Bayanai suna ajiyewa a browser din wannan computer kawai. A yi amfani da bayanan gwaji kawai.

Abubuwan gwaji:
1. Kirkiri customer account da PIN lambobi 4.
2. Shiga customer account.
3. Gwada demo deposit, withdraw da transfer tsakanin customer accounts biyu.
4. Duba transaction history, receipt/statement da CSV.
5. Shiga Admin Dashboard, duba customers da transactions.
6. Canza admin login, sauke JSON backup, sannan gwada restore da backup copy.

ENGLISH
Open index.html in a current Chrome or Microsoft Edge browser. This is an offline demonstration prototype. Data is stored in the current browser profile on this device only.

Default admin credentials: admin / 123456. Change these immediately in Admin Settings & Backup before showing the system to a customer. Keep the replacement credentials secure.

IMPORTANT LIMITATIONS
- This is NOT a licensed bank, wallet, payment service, or production financial platform.
- Deposits, withdrawals and transfers are simulated entries; no real money moves.
- No bank, BVN/NIN verification, SMS/OTP, payment gateway, server database, encryption-at-rest, or multi-device synchronization is included.
- Do not enter real customer identity, bank, card, PIN, or confidential information.
- For real-money deployment, obtain applicable regulatory/legal approvals and build a professionally secured server-side platform with payment-provider integration, monitoring, reconciliation, backups and independent security testing.
